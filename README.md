# Hardware-Mapped-Neural-Inference-Engine-for-Real-Time-Elderly-Fall-Detection
Real-time Embedded Edge AI and Hardware Acceleration system for elderly fall detection, integrating PSoC 5LP, ARM Cortex-M3, Verilog HDL, UDB digital logic, MAC accelerator, I2C sensor interfacing, multi-sensor fusion, fixed-point neural inference, and UART-based classification; achieved 2.27× speedup.
